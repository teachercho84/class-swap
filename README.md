# 수업 시간표 교체 프로그램

결근·출장 시 대체 교사를 자동/수동으로 찾아주는 정적 웹앱입니다.

👉 **바로 쓰기: [https://teachercho84.github.io/class-swap/](https://teachercho84.github.io/class-swap/)**

## 무엇을 하는 도구인가

교사가 결근·출장으로 수업에 빠질 때, 그 수업을 다른 시간으로 옮기거나(맞교체) 다른 선생님이 대신 맡을 수 있도록(대강) 후보를 자동으로 찾아줍니다. 시간표 데이터는 학기마다 엑셀 파일만 교체하면 되고, 브라우저 안에서만 계산되며 외부로 전송되지 않습니다.

## 사용 방법

1. 상단에서 본인 이름을 선택합니다.
2. 시간표 칸을 하나만 직접 클릭하면 그 시간 하나에 대한 교체·대강 후보를 바로 볼 수 있습니다.
3. 결근·출장이 여러 시간에 걸쳐 있다면, 시간표 아래 **"출장·결근 관리"**에서 요일·교시를 추가합니다(등록 즉시 자동으로 저장되어 새로고침해도 남아있습니다).
4. 등록된 결근에 대해 **"수동으로 대체 찾기"**(슬롯마다 직접 후보를 고름) 또는 **"자동으로 대체 찾기"**(시스템이 각 슬롯에 1명씩 자동으로 배정)를 선택합니다.
5. 슬롯 목록에서 슬롯 하나를 클릭해 후보를 고르면 그 슬롯과 관련된 선생님들의 미리보기가 뜨고, 모든 슬롯이 정해지면 전체 변경 시간표가 아래에 나타납니다.
   - **⚠ 표시**: 다른 슬롯을 수정한 여파로 이 슬롯의 선택이 더 이상 유효하지 않다는 경고입니다 — 다시 확인해주세요.
   - **"✕ 선택 해제"**: 그 슬롯만 다시 골라야 할 때 누르면 바로 후보 목록이 열립니다.
6. 전체 변경 시간표가 나타나면 **"인쇄하기"**를 눌러 종이로 뽑을 수 있습니다. 먼저 기준 날짜(첫 결근 요일의 날짜)를 넣으면 같은 주의 나머지 날짜가 자동으로 채워지고, 다음 주로 넘어가는 교체는 날짜를 직접 고칠 수 있습니다. 이어서 **"최종 변경 시간표 출력"**을 고르면 각 선생님 이름 옆에 `9/21(월) <-> 9/23(수)`처럼 바뀌는 날짜가 나오고, 바뀐 칸에도 날짜가 함께 찍힙니다. (**"수업 교체 일지 출력"**은 준비 중입니다.)
7. **"초기화"**를 누르면 이번에 등록한 결근·선택 내용이 전부 처음 상태로 돌아갑니다. 이 브라우저에 저장된 모든 교사의 결근·출장 기록이 함께 지워집니다.
   - 시간표 파일(`data.xlsx`)이 바뀐 뒤 처음 열 때도 저장돼 있던 결근·출장 기록이 자동으로 초기화되고, 안내 문구가 한 번 표시됩니다(학기 전환 시 예전 기록이 새 시간표에 남지 않도록).

## 대체 우선순위 안내

가장 많이 궁금해하실 부분이라 정리해둡니다.

1. **맞교체가 대강보다 항상 먼저 시도됩니다.** 맞교체(또는 이동수업 세트 교체) 후보가 하나라도 있으면 대강 후보는 아예 찾지 않습니다. 반대로 **"대강 우선"** 체크박스를 켜면 이 순서를 건너뛰고 곧장 대강 후보부터 보여줍니다.
2. **맞교체 후보 조건**: 상대 선생님이 같은 반을 다른 시간에 이미 담당하고 있어야 하고(과목은 달라도 됩니다), 서로의 시간에 둘 다 비어 있어서 맞바꿀 수 있어야 합니다. 이동수업(여러 반이 동시에 진행되는 세트 수업)인 경우엔 "세트간 교체"(세트 전체가 다른 세트와 통째로 자리를 맞바꿈) 또는 "개별 조합 교체"(세트가 통째로 빈 시간대로 옮겨가고, 반마다 대체 선생님을 매칭)로 나뉩니다.
3. **후보가 여러 명일 때**: 수동으로 찾을 때는 순위를 매기지 않고 가능한 후보를 전부 보여드리니 원하는 분을 직접 고르시면 됩니다. 자동으로 찾을 때는 그날 수업이 가장 적은 선생님을 우선 배정해, 특정 선생님에게 부담이 몰리지 않도록 합니다(동률이면 시간표상 먼저 나오는 분).
4. 맞교체 후보가 없으면 같은 교과 선생님(2순위) → 그래도 없으면 교과와 무관하게 전체 선생님(3순위, 참고용)까지 대강 후보로 보여드립니다.
